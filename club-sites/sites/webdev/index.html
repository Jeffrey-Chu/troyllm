    02 troy-high-llm
    
        
    The backend.
    
      
    
      
    
        
    Every site on this page is hosted on one Firebase project, troy-high-llm. Jeffrey Chu set it up and manages it, along with the club's GitHub. It handles Google sign-in, a separate locked-down database for each site, and deploys every site automatically whenever someone pushes.
    
        
    It started as the points system for the Troy High LLM club: members request to join, officers approve them, and awarded points can't be edited after the fact.
    
        
    
          
          
    gitpushA member pushes to GitHub
    
          
    ✓testSecurity rules get tested
    
          
    fbdeployFirebase deploys
    
          
    14liveEvery site updates
    
        
    
        
    Made by Jeffrey Chu

    04 About
    
          
    About the club.
    
          
    Troy Web Development started in 2023 as Web Development Education, a club where members taught each other how to build for the web. We still teach, but most meetings now go into building and updating sites for Troy clubs.
    
        
    
      
    
      
      
        
    1. 2023Web Development Education
      Yeowon Yoon co-founds the club. Members give lectures on building for the web.
      2. 
        
    2. 2023troywebdev.com
      Our first site, a directory of Troy clubs used by more than 100 student organizations.
      3. 
        
    3. YearlyTech Fair and Food Fest
      Picked for the Troy Tech Fair out of 125 clubs every year since 2023, and at International Food Fest every year too.
      4. 
        
    4. 2026One backend, every club
      Jeffrey Chu's Firebase project hosts every club site we build.
      5. 
      
    
      
    
        
    When
    Every other Thursday
    Lunch, Room 411. Club news goes out on Google Classroom.
    
        
    What
    Club websites
    Clubs ask us for a site. A member takes the lead, builds it with the club, and keeps it updated after launch.
    
        
    Who
    Anyone at Troy
    No experience needed. Come to a meeting, pick a project, and learn by building it.
    
        
    
          
    Start
    How it started
    Yeowon Yoon co-founded the club in 2023 and led it through 2026. Our first site, troywebdev.com, was a directory used by more than 100 student organizations. It and our old club kiosk site are retired now. This site replaces both.
    
          
    Code
    Where the code lives
    Every site lives in one GitHub repository, managed by Jeffrey Chu, and goes live automatically on Firebase when changes are pushed. See the repo.
